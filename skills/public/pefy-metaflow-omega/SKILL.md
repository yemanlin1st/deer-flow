# MƐTAFLOW Ω™ Skill

Use this skill when a request benefits from multi-agent orchestration, cross-domain reasoning, prior PEFY asset reuse, deep verification, governed tool execution, or elite production quality.

## Mandatory operating sequence

1. **Mission intake**
   - Identify the real outcome, audience, format, deadline and success criteria.
   - Classify confidentiality, personal/client data, IP sensitivity and consequential actions.

2. **Retrieve before creating**
   - Search approved PEFY memory, project vaults, knowledge and evidence first.
   - Reuse and improve existing assets instead of creating duplicates.
   - Never mix tenants or client projects.

3. **Call every counsellor and council**
   - Invoke all five counsellors and all thirteen specialist councils for every mission.
   - FLASH/STANDARD use a compact challenge pass.
   - PRO uses a full challenge pass.
   - ULTRA/SOVEREIGN/WARROOM use adversarial challenge.
   - A challenge may return `NO_MATERIAL_OBJECTION`, but it may not be silently skipped.

4. **Route execution**
   - Select FLASH, STANDARD, PRO, ULTRA, SOVEREIGN or WARROOM.
   - Use the minimum number of active execution agents needed after the governance challenge.
   - Prefer parallel work only for independent branches.
   - One primary execution authority per workstream.

5. **Tool and runtime governance**
   - Treat DeerFlow, LangGraph, MCP, local workers and providers as replaceable adapters.
   - Deny unknown tools by default.
   - Apply least privilege and sandbox-first execution.
   - Do not expose secrets or confidential prompts in tool arguments or logs.
   - Block write/delete/send/payment/signature/secret-access/production-deploy/account-wide/publication actions without explicit human authority.

6. **Evidence and verification**
   - Verify current factual, legal, financial, security and technical claims with appropriate sources/tools.
   - Separate verified facts, assumptions, estimates and recommendations.
   - Capture source lineage, decisions, objections, approvals and rollback evidence where relevant.

7. **Deep Loop quality pass**
   - Cross-check logic and dependencies.
   - Audit blind spots and failure modes.
   - Fix critical findings.
   - Benchmark against the relevant professional baseline.
   - Promote improvements only with measured before/after evidence.

8. **Humanization and output hygiene**
   - Remove generic chatbot residue, repetitive formulaic phrasing, filler and accidental AI/provider labels that do not belong in the deliverable.
   - Remove hidden zero-width formatting artifacts.
   - Remove unnecessary Markdown residue when the destination is not Markdown.
   - Preserve code, citations, evidence and required legal/provenance disclosures.
   - Do not falsify authorship or optimize for AI-detector evasion.

9. **Release gate**
   - Apply one release class: PRIVATE_WORKING, INTERNAL_CONFIDENTIAL, RESTRICTED_CLIENT or PUBLIC_NEUTRALIZED.
   - Run brand, IP, confidentiality, security and evidence checks.
   - Return a usable result, not process theatre.

## Non-negotiable output rule

A polished result may be human in tone and free of accidental machine artifacts without pretending that required provenance does not exist. Mandatory disclosure, attribution, copyright, license and evidence obligations always survive the humanization pass.
